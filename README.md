# Panfletos

Editor web de panfletos de loja, feito para substituir o Photoshop.

- **Natura:** https://panfleto.estrutura.dev/natura/ (precisa do Chrome ou do Edge)

Como usar o editor e as decisões de projeto estão em [ESPECIFICACAO.md](ESPECIFICACAO.md). O deploy no Cloudflare Pages está descrito em [PUBLICACAO.md](PUBLICACAO.md).

Para rodar localmente:

```
python servidor.py
```

Depois abra http://localhost:8765/natura/.
